# E-Learning Platform Usability Analysis

## Overview

This project presents a usability analysis of a redesigned e-learning course player using statistical evaluation techniques and UX research methods.

The study evaluates how different interface layouts affect:

* Task efficiency
* Interaction effort
* Learner satisfaction
* Overall usability performance

The analysis was conducted using usability testing data provided for an academic usability evaluation exercise. Statistical methods were applied to identify usability issues, evaluate interface performance, and support evidence-based design recommendations.

---

# Project Objectives

The main objectives of this project were to:

* Analyse usability testing data from multiple e-learning interface designs
* Evaluate task efficiency using statistical analysis
* Examine the relationship between interaction effort and learner satisfaction
* Identify usability issues affecting user experience
* Provide data-driven recommendations for interface improvement

---

# Research Questions

## 1. Task Efficiency Analysis

Does the layout design significantly affect task efficiency for desktop users?

A paired-sample t-test was conducted to compare task completion times between:

* Design A
* Design B

---

## 2. Interaction Effort and Satisfaction Analysis

Is there a relationship between interaction effort and learner satisfaction?

Pearson correlation analysis was conducted to evaluate the relationship between:

* Number of clicks
* Overall learner satisfaction

# Key Findings

## Task Efficiency

The paired-sample t-test revealed a statistically significant difference in task completion time between Design A and Design B.

### Key findings:

* Design A enabled faster task completion
* Users completed tasks more efficiently using Design A
* Layout design significantly affected usability performance

---

## Interaction Effort and Satisfaction

The Pearson correlation analysis identified a strong negative relationship between interaction effort and learner satisfaction.

### Key findings:

* Higher numbers of clicks were associated with lower satisfaction
* Reducing unnecessary interactions improves user experience
* Interaction effort directly impacts learner satisfaction
